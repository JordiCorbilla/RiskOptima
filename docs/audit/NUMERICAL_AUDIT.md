Baseline v2.8.1 at `756293c2948daae570c11fae2e969383f5b07749`. Phase 1 preserves the callable API where the original calculation was valid. Corrected results can differ materially for Merton options, shortfall with atoms, and financial ML.

## Losses, missing observations, and ties

RiskOptima uses positive loss as the sign convention for adverse outcomes. For equal-weight losses, calculate the tail size as `n*(1-confidence)`. Include all observations strictly above the cutoff and allocate the remaining mass equally across observations equal to it. Divide by the requested tail mass. If this mass is less than one observation, ES equals the worst loss. Component contributions use the same observation weights and sum to portfolio ES up to floating-point error.

At 60% confidence, losses [0, 0, 0, 10] have 1.6 observations of tail mass. Their ES is `(10 + 0.6*0)/1.6 = 6.25`. In a portfolio with losses [0.20, 0.10, 0.10, 0.00] at 62.5% confidence, the worst observation receives full weight and the two tied observations each receive one quarter before normalization. The cutoff used by this empirical integral can differ from the displayed interpolated VaR. Missing and infinite scalar losses are excluded. Component attribution excludes the entire row if any asset return is missing or infinite. A sample with no usable observations is undefined and raises `ValueError`.

## Limits of the evidence

- A filtered HMM posterior is causal only conditional on fixed parameters. An in-sample model fits parameters using the entire sample. Historical signal evaluation requires an earlier training cutoff and inference with parameters available at each evaluation date.
- The backtest uses the timestamps and prices supplied by the caller. The checks do not establish vendor publication timestamps, revisions, historical index membership, split adjustments, or survivorship-free data. Same-close execution in the separate legacy signal tools still needs its own review.
- The covariance contract cannot infer percentage versus decimal returns or source frequency from an untagged matrix. `periods_per_year` must correspond to the observation sampling frequency. Heterogeneous calendars and serial-correlation-aware aggregation remain open.
- Black-Litterman retains the portfolio workflow's historical prior proxy and confidence calibration heuristic. This work verifies timing, label alignment, and units of inputs, with no evidence on market equilibrium calibration or forecast profitability.
- Extreme-tail Merton inputs, implied-volatility identifiability near zero vega, HMM density clipping in extreme regimes, legacy Heston and SABR approximations, and production pricing-model calibration remain outside the validated input ranges.
